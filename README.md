# Pockity — Free Offline Installer

![Category](https://img.shields.io/badge/Finance_Tracker-blue?style=flat-square)

## About

Pockity is a minimal personal finance and expense tracking application for macOS and iOS. Log income and expenses with categories, set budgets, view spending trends, and understand where money goes without the complexity of full accounting software. Pockity's clean, native Apple design and privacy-first approach to local data storage appeal to users who want simple expense tracking without cloud services.

## Common Problems & Limitations

- **Apple Only** — macOS and iOS; no Android or Windows version
- **Commercial License** — Paid application
- **No Bank Sync** — Manual entry only; no automatic bank or card transaction import
- **Reporting Limits** — Basic reports without the depth of full personal finance applications
